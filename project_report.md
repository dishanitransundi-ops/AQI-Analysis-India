AQI Analysis of India Using Python

1. Introduction

Air pollution is a major environmental problem in India. This project analyzes Air Quality Index (AQI) data from Indian cities from 2015 to 2020 using Python.

2. Objectives

- Analyze air pollution levels across Indian cities.
- Compare major pollutants such as PM2.5, PM10, NO2 and SO2.
- Study yearly AQI trends.
- Create visualizations and an interactive dashboard.

3. Tools and Technologies

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Plotly and Dash
- Jupyter Notebook and VS Code
- Google Gemini AI

4. Dataset

The project uses the Air Quality Data in India dataset for 2015–2020. The dataset contains city names, dates, pollutant levels, AQI and AQI categories.

5. Methodology

The dataset is loaded using Pandas, checked for missing values, cleaned and analyzed. Graphs are created to compare pollutant levels, cities and yearly AQI trends. An interactive dashboard allows users to explore AQI information by city.

6. AI Integration

Google Gemini AI was used to generate a policy brief based on the project's findings and suggest measures to reduce air pollution.

7. Conclusion

This project helps us understand air pollution patterns across Indian cities through data analysis and visualization. The results can support awareness and encourage measures to improve air quality.
